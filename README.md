# Brasileirão Série A 2026

Página de classificação e próximos jogos do Brasileirão Série A, feita com React + TypeScript + Tailwind CSS (mobile first).

## Como rodar

```bash
npm install
npm run dev
```

## Funcionalidades

- Classificação com os 20 clubes (renderizada com `map`)
- Faixa lateral colorida por zona (Libertadores, Sul-Americana, Rebaixamento)
- Filtro por zona (chips) com `useState`
- Favoritar clubes (estrela) com `useState` e contador no cabeçalho
- Próximos jogos (listagem secundária), fixos na lateral no desktop
- Layout responsivo: mobile (1 coluna), tablet `md:` (2 colunas) e desktop `lg:` (classificação + lateral)
